# NIKKE // FAN ARCHIVE + AETHER // REQUIEM

Unofficial fan card sets rendered with p5.js. Single-file apps, no build step, no tracking.

- `index.html` — NIKKE // FAN ARCHIVE (36 cards)
- `aether.html` — AETHER // REQUIEM (5 procedural cards)

Controls: move to tilt · click to flip · click a side card or ← → to cycle · **G** for the binder · **S** to export a PNG.

Fan project. Not affiliated with Shift Up.
